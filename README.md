# IN4310 – Deep Learning for Image Analysis

**University of Oslo (UiO)**  
**Repository owner:** Zejing Wang

## Overview

This repository is intended for coursework, exercises, and practical experiments related to **IN4310: Deep Learning for Image Analysis**.

The aim is to document the application of deep learning to image data, with an emphasis on understanding model architectures, training procedures, and reliable evaluation of image-analysis results.

## Areas of Interest

Potential topics for future work include:

- Image preprocessing and dataset preparation.
- Convolutional neural networks and other deep learning architectures for images.
- Image classification and, where relevant, other image-analysis tasks.
- Training, validation, regularization, and hyperparameter selection.
- Evaluation, visualization, and interpretation of model predictions.

These are possible areas of study rather than claims about completed projects.
